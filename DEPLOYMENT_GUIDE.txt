// DEPLOYMENT & INTEGRATION GUIDE
// XAO ETHDenver NFT - Base Chain

========================================
1. CHOOSE YOUR CONTRACT VARIANT
========================================

Option A: XAOETHDenverNFT.sol (Standard ERC721)
- Standard ERC721 with custom optimizations
- Good for simpler deployments
- Full enumerable support
- Slightly higher gas costs

Option B: XAOETHDenverNFT_ERC721A.sol (RECOMMENDED)
- Uses Azuki's ERC721A for ~90% gas savings on minting
- Lower mint costs (important for free mints!)
- Recommended for high-volume free mint events
- Slightly larger bytecode

========================================
2. PRE-DEPLOYMENT SETUP
========================================

A. IPFS/Metadata Hosting
---------------------------
1. Prepare 10,000 images:
   - Each persona has unique visual style
   - Include trait variations
   - Size: ~100-500KB each for web optimization
   - Format: PNG recommended (transparency support)
   - Naming: 0.png, 1.png, 2.png ... 9999.png

2. Upload to IPFS:
   - Use Pinata, NFT.storage, or similar
   - Get base URI: https://ipfs.io/ipfs/QmXXXXXX/
   - Example full metadata URI: https://ipfs.io/ipfs/QmXXXXXX/0

3. Metadata JSON:
   - Can be on-chain (via getMetadata()) or external
   - If external, host alongside images
   - Each JSON follows OpenSea standard

B. Base Network Setup
---------------------------
1. Network: Base Mainnet
   - RPC: https://mainnet.base.org
   - Chain ID: 8453

2. Environment:
   - Need ~0.5 ETH on Base for deployment + testing
   - Have owner wallet ready (for mint window control)

C. Contract Configuration
---------------------------
Example deployment with Hardhat:

const baseURI = "https://ipfs.io/ipfs/QmXXXXXX/"; // IPFS URI

const nftContract = await ethers.deployContract("XAOETHDenverNFT_ERC721A", [baseURI]);
const deployedAddress = await nftContract.getAddress();

console.log("XAO ETHDenver NFT deployed to:", deployedAddress);

  const { data, isLoading, write } = useContractWrite({
    address: '0xContractAddress',
    abi: XAO_ABI,
    functionName: 'mint',
    args: [1], // quantity
  });

  return (
    <button 
      onClick={() => write()} 
      disabled={isLoading}
    >
      Mint XAO NFT
    </button>
  );
}

// Check mint activity
async function getMintStatus(contractAddress) {
  const provider = new ethers.JsonRpcProvider('https://mainnet.base.org');
  const contract = new ethers.Contract(
    contractAddress,
    XAO_ABI,
    provider
  );
  
  const totalMinted = await contract.totalSupply();
  const remaining = await contract.getRemainingSupply();
  const distribution = await contract.getPersonaStatus();
  
  return { totalMinted, remaining, distribution };
}

========================================
12. TROUBLESHOOTING
========================================

Problem: "Mint window closed"
Solution: Call setMintWindow() with current block.timestamp + duration

Problem: "Wallet limit exceeded"
Solution: This is by design (max 10 per wallet). Use different wallet.

Problem: Metadata not loading
Solution: 
  1. Verify baseURI is correct
  2. Check IPFS availability
  3. Ensure image files exist in IPFS
  4. Test via tokenURI() function

Problem: High gas costs
Solution:
  1. Use ERC721A version (saves ~250 ETH for 10k mints)
  2. Batch transactions
  3. Mint during low gas periods

Problem: Contract verification failing
Solution:
  1. Ensure constructor args match deployment
  2. Use exact compiler version (0.8.20)
  3. Include all dependencies
  4. Check formatting/spaces
